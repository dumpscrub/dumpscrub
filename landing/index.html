Quickstart

Three commands from zero to a scrubbed, CI-gated dump.

1 · install
curl -fsSL https://raw.githubusercontent.com/dumpscrub/dumpscrub/main/install.sh -o install.sh
sh install.sh   # verifies SHA-256, installs to /usr/local/bin
2 · scrub a dump
# INSERT or native COPY format — both work
cat prod.sql | dumpscrub > staging.sql

# fix a false positive without touching code
dumpscrub --ignore users.phone --mask orders.ship_address=street_address < prod.sql > staging.sql
3 · gate CI
# .github/workflows/scrub.yml
- uses: dumpscrub/dumpscrub@v1
  with:
    input: prod.sql
    output: staging.sql
    report: scrub-report.json
    fail-on-pii: "true"
